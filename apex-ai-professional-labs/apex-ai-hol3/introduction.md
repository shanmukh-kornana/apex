# Introduction

## About This Workshop

The Talent Management System schema is ready now. Before you create the Talent Acquisition Portal (TAP) and Employee Self-Service Portal (ESS), this module provides a guided tour of the Oracle APEX development environment. This lab will help you understand the Oracle APEX components and App Builder areas that you will use while building applications in later modules.

You will explore App Builder, SQL Workshop, Team Development, and Gallery. You will also install and run a professionally built Gallery application that you can keep as a reference while building TAP and ESS.

Estimated Workshop Time: 20 minutes

## What You Will Do

You will not create a new application in this module. You will install a Gallery sample application and review its navigation, layouts, forms, and reports as professional reference patterns.

## Objectives

In this workshop, you will:

- Identify the purpose of App Builder, SQL Workshop, Team Development, and Gallery.
- Navigate the App Builder home page and review an application's main development areas.
- Browse Gallery sample apps and starter apps.
- Install and explore a professionally built reference application.
- Recognize design patterns to reuse when building TAP and ESS.

## Prerequisites

- Complete Module 2, **Using SQL Workshop**.
- An APEX workspace.
